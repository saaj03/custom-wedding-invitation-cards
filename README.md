# 🕌 Custom Islamic Wedding Invitation Cards

A free, customizable Islamic & Muslim Marriage Invitation Creator built with **Next.js 15**, **Tailwind CSS**, and **Framer Motion**.

Create beautiful digital Islamic wedding invitations for Nikah, Walima, and Muslim marriage ceremonies. Customize names, dates, venues, photos, colors, and invitation details.

## ✨ Features

- Beautiful Islamic and Muslim wedding invitation designs.
- Nikah and Walima invitation layouts.
- Personalized bride and groom names.
- Custom wedding dates, times, and venues.
- Elegant animations and transitions.
- Live wedding countdown timer.
- Event timeline.
- Photo gallery with lightbox.
- RSVP form integration ready.
- Background music option.
- QR code generation and download.
- WhatsApp and social media sharing.
- Responsive mobile-friendly design.
- SEO-friendly pages and metadata.

## 🚀 Quick Start

Clone the repository:

```bash
git clone https://github.com/saaj03/custom-wedding-invitation-cards.git
cd custom-wedding-invitation-cards
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Open http://localhost:3000

## ⚙️ Customize Your Invitation

Edit the following file:

`src/config/wedding.ts`

Customize:
- Bride and groom names
- Wedding date and time
- Nikah and Walima events
- Venue and address
- Photos and gallery
- Music URL
- Theme colors
- Invitation details
